# Power Iterated Graph Transformation

This repository holds the data used for the figures used on the PIGT paper.

The 9comm_* directories are for the benchmark 9 communities network. The '9comm_fpt' holds example networks and scripts.
The lj38_* directories are for the benchmark lj38 cluster. The lj38_fpt directory holds scripts that generate example networks.

The lj100_fpt directory holds data for the LJ100 ring polymer knot. It has a mixture of MFPT calculations, reduced networks, Dijkstra shortest pathways and FP plots.

All networks are analysed with PATHSAMPLE.
